These rasters are generated by `Tools/SceneDirectoryProof/SceneDirectoryProof.cpp` from the real `WorkspacePanel`, `EditorPanel`, `SceneDirectoryPanel`, and `TexturePaintPanel` through the production recording surface.

- `editor-scene-transfer.png` — Scene Import with FBX/glTF/GLB/OBJ/USD/USDZ/DAE/STL/PLY/Alembic format rail, editable name/tags/location, unit scale, forward/up axes, normal handling, transforms, materials, animation, vertex colours, triangulation, and custom properties.
- `editor-scene-export.png` — Scene Export after its format carousel advances; export-specific flags include modifiers, tangent space, and baked animation.
- `editor-layer-flatten.png` — non-destructive Export Flattened with image format, 128–16K resolution, target preset, metadata, packing, bit-depth, normal convention, dilation, and colour-space controls.
- `editor-layer-export.png` — separate texture-set Export after format, resolution, and target-preset carousels advance to JPEG, 4K, and Unreal ORM. The packing readout confirms AO:R, Roughness:G, Metallic:B.

The runtime scenarios press the real footer actions and carousel arrows rather than setting the resulting readings directly.
